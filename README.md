# منيو QR عربي للمطعم

منيو ويب متجاوب باللغة العربية، مع تصنيفات وبحث وسلة بسيطة وإرسال الطلب عبر واتساب.

## الملفات
- `index.html`: هيكل الصفحة.
- `style.css`: التصميم والألوان.
- `menu-data.js`: اسم المطعم ورقم واتساب والأصناف والأسعار وروابط الصور.
- `app.js`: البحث والتصنيفات وتجميع الطلب وإرساله إلى واتساب.

## 1) تخصيص المنيو
افتح `menu-data.js` بأي محرر نصوص، وعدّل:
- `restaurantName`: اسم المطعم.
- `tagline`: العبارة تحت الاسم.
- `whatsappNumber`: رقم واتساب بصيغة دولية بدون علامة + أو الصفر الأول. مثال: `01012345678` يصبح `201012345678`.
- `categories`: أسماء الأقسام.
- `items`: الأصناف. لكل صنف `id`, `name`, `category`, `description`, `price`, `image`.

احذف الأصناف التجريبية وأضف أصناف المطعم الحقيقية. استخدم روابط صور مباشرة تنتهي بصيغة صورة أو روابط صور مستضافة على خدمة موثوقة. ويمكنك لاحقًا وضع الصور داخل المشروع وتغيير روابطها إلى مسارات محلية.

**مهم:** أسعار وأسماء الأصناف الحالية أمثلة تجريبية فقط وليست أسعارًا حقيقية.

## 2) تجربة المنيو على جهازك
افتح `index.html` في المتصفح. جرّب البحث، اختيار قسم، إضافة أصناف، ثم زر الطلب عبر واتساب. لن يعمل إرسال واتساب قبل وضع رقم حقيقي في `menu-data.js`.

## 3) النشر المجاني على Cloudflare Pages عبر GitHub
1. أنشئ حسابًا مجانيًا على GitHub.
2. أنشئ مستودعًا جديدًا (Repository) وليكن اسمه `restaurant-menu`.
3. ارفع الملفات الأربعة إلى المستودع: `index.html`, `style.css`, `app.js`, `menu-data.js`.
4. أنشئ حسابًا مجانيًا على Cloudflare.
5. من لوحة Cloudflare افتح **Workers & Pages** ثم **Create application** ثم **Pages**.
6. اختر **Connect to Git** واربط حساب GitHub.
7. اختر مستودع `restaurant-menu`.
8. في إعدادات البناء:
   - Framework preset: `None`
   - Build command: اتركه فارغًا
   - Build output directory: `/` أو `.` حسب ما تقبله واجهة Cloudflare للمجلد الرئيسي.
9. اضغط Deploy. سيعطيك Cloudflare رابطًا مثل `restaurant-menu.pages.dev`.

قد تتغير أسماء الأزرار قليلًا حسب تحديث لوحة التحكم.

## 4) إنشاء QR Code
بعد التأكد أن الرابط يعمل على الموبايل:
1. انسخ رابط `pages.dev`.
2. أنشئ QR Code للرابط من أي مولّد QR موثوق.
3. امسحه بكاميرا موبايل مختلفة قبل الطباعة.
4. اطبع الكود مع عبارة: «امسح هنا لمشاهدة المنيو والطلب».

## 5) تحديث المنيو بعد الطباعة
عدّل `menu-data.js` في GitHub ثم احفظ التعديلات (Commit). Cloudflare Pages سيعيد نشر الموقع تلقائيًا، وسيظل رابط الموقع وQR كما هما.

## ملاحظات
- الاستضافة على Cloudflare Pages مجانية ضمن حدود الخطة المجانية الحالية.
- تحميل الخط والصور يتطلب اتصال إنترنت.
- لا تضع بيانات حساسة في ملفات الموقع؛ الملفات عامة ويمكن لأي شخص الاطلاع عليها.
- زر واتساب يجهز رسالة بالطلب والإجمالي، لكنه لا ينفذ الدفع أو يؤكد الطلب تلقائيًا.
